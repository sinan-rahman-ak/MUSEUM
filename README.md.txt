# VR Museum

A virtual reality museum experience built in Unity featuring interactive 3D models and exhibits.

## Project Structure

```text
MUSEUM/
├── Assets/
│   ├── models/       # 3D models and assets (.dae, .zip tracked via Git LFS)
│   ├── Scenes/       # Unity scenes 
│   ├── XR/           # XR interaction setups
│   └── ...
├── Packages/
├── ProjectSettings/
└── README.md

```

## Requirements

* **Unity Version:** 2022.3.12f1 or later
* **Toolkit:** XR Interaction Toolkit
* **Hardware:** VR-compatible headset

## Setup & Run

1. Clone or download this repository.
2. Open **Unity Hub**.
3. Click **Add project from disk** and select the `MUSEUM` folder.
4. Open the project and load `Assets/Scenes/SampleScene.unity`.
